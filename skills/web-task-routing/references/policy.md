# Web Task Routing Policy

## 链路选择

- `[MUST]` 先判断是否需要浏览器，再判断任务类型、会话依赖和复用需求；不得无依据直接使用最重工具。
- `[DEFAULT]` 公开网页信息提取优先使用普通网页检索/抓取；只有需要真实渲染、登录态、现有标签页、扩展桥接或复杂交互时，才升级到浏览器链路。
- `[DEFAULT]` `agent-browser`：公开网页读取、轻交互、一次性低风险表单。
- `[DEFAULT]` `Playwright MCP`：依赖当前浏览器登录态、现有 Chrome/Edge 标签页、扩展桥接或 MCP 原生会话控制。
- `[DEFAULT]` `Playwright CLI`：需要脚本化复用、trace/network/console、页面调试、localhost 问题复现或回归验证。
- `[MUST]` 明确要求“连接、附着、接管、复用当前 Chrome/Edge 窗口、标签页或会话”时，视为现有会话依赖，优先 `Playwright MCP`。
- `[MUST]` 本地页面调试、控制台报错、白屏、资源加载失败、接口失败、运行时异常或回归验证，默认使用 `Playwright CLI` 后台链路；除非用户要求观察，不主动打开浏览器窗口。
- `[MUST]` 链路选择理由必须与所选链路一致；若理由是公开网页读取、无需登录态或一次性提取，不得优先选择 `Playwright MCP`，除非已说明真实渲染或抓取受限等升级依据。

## 升级与降级

- `[MUST]` 选择链路前确认当前环境是否提供该工具与所需能力；首选不可用时，按能力最接近且成本最低的方式切换。
- `[MUST]` 不因“可能动态渲染、可能交互、提到浏览器”直接升级；必须基于关键字段缺失、抓取受限、会话依赖或交互失败等证据。
- `[MUST]` 普通抓取受限时，说明受限现象、为什么不是字段不存在、升级后是否从真实页面读到目标信息。
- `[MUST]` 公开页面抓取受限但不依赖登录态时，优先使用能读取实际渲染结果的轻量浏览器链路；不要默认选择 `Playwright MCP`，除非任务明确需要复用当前浏览器登录态、标签页、cookie 或扩展状态。
- `[DEFAULT]` `agent-browser` 因同类原因连续 2 次失败时升级到 `Playwright MCP`；若需要稳定复现、调试取证或回归执行，升级到 `Playwright CLI`。
- `[DEFAULT]` `Playwright MCP` 不可用时：无登录态依赖降级到 `agent-browser`；需要脚本化调试或验证时升级到 `Playwright CLI`。
- `[DEFAULT]` `Playwright CLI` 不可用时：一次性且依赖登录态改用 `Playwright MCP`；轻量查看与提取改用 `agent-browser`。
- `[MUST]` 升级或降级后，在交付中说明原链路、触发原因、切换后结果和影响范围。

## 风险闸门

- `[STOP]` 涉及付款、转账、发帖、发消息、批量删除、批量修改、提交订单、提交审批等高风险网页操作时，不自动执行最终提交动作，必须停在提交前等待确认。
- `[MUST]` 涉及隐私数据、生产后台、客户数据时，只做最小必要查看与提取；输出前脱敏，不复述敏感原文。
- `[MUST NOT]` 不为规避风控、验证码或权限限制而擅自切换到更高权限链路。
- `[MUST]` 需要账号登录但无可复用登录态时，不代替用户登录、注册、找回密码或接收验证码；停在需要用户介入的位置。

## 执行要求

- `[MUST]` 开始网页任务时，用一句话说明所选链路及原因。
- `[DEFAULT]` 页面变化后只提取最小必要状态，不重复回传冗长页面结构。
- `[DEFAULT]` 网页任务交付优先包含结论、关键证据和下一步，不输出低价值过程噪声。
- `[MUST]` 浏览器调试、页面取证或回归截图写入当前目标项目内 `.codex/browser-screenshots/`。
- `[MUST]` 调用截图工具时显式传入带目录的 `filename`；不得依赖默认文件名落到当前工作目录。

## 成功输出模板

```text
网页任务结果
- 目标：一句话说明本次网页任务要完成什么。
- 所选链路：`agent-browser` / `Playwright MCP` / `Playwright CLI`。
- 选择原因：说明为什么该链路最合适，是否依赖登录态、现有会话、调试能力或复用需求。
- 执行结果：说明是否完成；若部分完成，说明未完成项。
- 关键证据：
  - 页面/对象：站点、页面标题、关键区域或对象。
  - 核心发现：提炼 1-3 条最重要事实。
  - 必要细节：时间、状态、数量、按钮状态、是否可见等。
- 升级/降级：若发生链路切换，说明原链路、触发原因、切换后结果。
- 风险与限制：说明登录态、风控、验证码、页面不稳定、数据时效性等限制。
- 下一步：给出继续执行的最小建议；若需要用户确认，明确停在何处。
```

## 失败处理

- `[MUST]` 失败时先归类，再决定后续动作；不得跳过归类直接给笼统结论。
- `[DEFAULT]` 登录/会话类：未登录、登录过期、会话丢失、当前浏览器上下文不可复用；优先判断是否需要用户恢复会话。
- `[DEFAULT]` 页面结构类：DOM 变化、元素引用失效、按钮不可见、懒加载未出现；优先等待、刷新、重新定位或回到上一步。
- `[DEFAULT]` 风控/权限类：验证码、频率限制、权限不足、额外认证；停止高频重试，不尝试规避。
- `[DEFAULT]` 浏览器链路类：扩展桥接失败、MCP 连接异常、CLI 启动失败、页面崩溃；先重建当前链路，再按能力切换。
- `[DEFAULT]` 数据类：搜索为空、页面暂无数据、排序/推荐干扰、页面非目标对象；优先确认查询条件、筛选、时间范围和目标对象。
- `[MUST]` 失败后发生链路切换时说明原链路、触发原因和切换结果。

```text
网页任务失败结果
- 目标：一句话说明原本要完成的网页任务。
- 所选链路：`agent-browser` / `Playwright MCP` / `Playwright CLI`。
- 当前状态：未完成 / 部分完成 / 已停止在确认前。
- 失败类别：登录/会话类 / 页面结构类 / 风控/权限类 / 浏览器链路类 / 数据类。
- 失败结论：一句话说明失败点或未完成原因。
- 主要阻塞点：
  - 阻塞类型：如登录态失效、验证码、权限不足、页面结构变化、元素定位失败、网络异常、会话丢失、目标按钮不可见等。
  - 具体现象：说明页面表现、报错类别或无法继续的直接原因。
- 已尝试动作：列出关键步骤，不堆叠低价值过程。
- 当前判断：说明这是暂时性问题、环境问题、页面改版问题，还是必须用户介入的问题。
- 升级/降级：若发生链路切换，说明原链路、触发原因、切换后结果。
- 风险与限制：说明数据时效性、会话依赖、风控限制、页面不稳定性或当前环境限制。
- 下一步：给出继续执行的最小建议；若需用户介入，明确需要确认、登录、输入验证码或提供目标信息。
```
